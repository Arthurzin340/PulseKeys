# Pulse Keys

Jogo de ritmo touch feito para projetor/quadro interativo.

## Recursos
- 3 espaços de toque, sem exigir dois toques simultâneos
- Cadastro e login local com nome + senha numérica de 4–6 dígitos
- Melhor pontuação salva por usuário neste navegador
- 5 dificuldades: Noob, Médio, Difícil, Insano e Marcus
- Playlist própria para cada dificuldade
- Cada faixa tem link para ouvir no YouTube antes de jogar
- Dificuldade escolhida filtra automaticamente a playlist
- Começo de cada fase mais lento e aceleração progressiva
- Depois dos primeiros 5 acertos, a aceleração fica bem mais forte
- Partidas curtas de aproximadamente 18–20 segundos
- Pause com Continuar, Reiniciar e Voltar ao lobby
- Música sintetizada pelo navegador, sem depender do YouTube para tocar o jogo
- Compatível com mouse, toque e GitHub Pages

## Observação sobre as músicas
Os links do YouTube servem para o aluno ouvir as referências das faixas. O jogo não baixa nem incorpora o áudio do YouTube; ele gera uma trilha instrumental simples localmente com Web Audio API. Para usar uma música externa dentro do jogo, é necessário ter autorização/licença adequada.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css` e `script.js`.
3. Em Settings > Pages, selecione a branch principal e a pasta `/root`.
4. Salve e abra o endereço do GitHub Pages.
